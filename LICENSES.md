# License allocation

This table summarizes the allocation already declared in the catalog header,
[LICENSE](LICENSE), [LICENSE-CODE](LICENSE-CODE) and [NOTICE](NOTICE).

| Material | Repository license | Included scope |
|---|---|---|
| Standard text and metric definitions | CC BY 4.0 | Catalog cards, principles, explanatory method/rubric and review documentation |
| Code and executable schemas | MIT | Python/JavaScript/SQL, JSON schemas, automation, tests and executable formula implementations |
| Generated catalog exports | CC BY 4.0 for definitions | Preserve attribution and source/version metadata |
| Generated recipe/profile exports and workbooks | MIT for executable logic; CC BY 4.0 for embedded standard definitions | Preserve both notices when distributing the combined artifact |
| Dependency code and native engines | Their respective upstream licenses | Dependency references do not relicense third-party packages or engines |

Framework names/references are informative associations, not incorporated standard
text or conformity certificates. Framework editions and mapping evidence are
tracked separately. No restricted draft text is part of these implementation
profiles. Public release artifacts contain the technical source, contracts and
verification information needed to reproduce the result.
